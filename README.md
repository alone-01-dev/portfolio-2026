# Portfolio — P. Viji Prakash Sharma

Personal portfolio site for Viji Prakash Sharma, Java Full Stack Developer.

Live: https://alone-01-dev.github.io/Portfolio-/

## Sections
- Home — intro with typing effect
- About — bio + technical skills
- Experience — timeline of roles (TapAcademy, Star Bazaar, Altruist Technologies)
- Projects — Food Delivery App, E-Commerce Price Tracker
- Education & Certifications
- Contact — form + direct details

## Stack
Plain HTML / CSS / JS. Typed.js for the typing effect, ScrollReveal.js for scroll animations, Font Awesome + Unicons for icons.

## Updating content
All content lives in `index.html` (`portfolio.html` is kept as a duplicate for compatibility). Styles are in `portfolio.css`. Behavior/animations are in `script.js`.
